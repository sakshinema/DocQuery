# Product Notes

## Target user

An analyst, operations engineer, recruiter, finance user, or support person who receives a stream of inconsistent documents and needs to answer questions without manually opening each file.

## Core user promise

> “Give me the answer quickly, but let me verify it in the source.”

## Non-goals for this submission

DocQuery is not a universal OCR platform, contract lifecycle management system, records retention product, or multi-tenant enterprise knowledge base. The five-day build is intentionally focused on the ingestion → retrieval → evidence loop.

## Demo corpus

For the strongest demo, use 3–5 documents of different shapes, for example:

- two invoices with different layouts;
- a resume or profile document;
- a policy/contract with dates and obligations;
- a small CSV export.

Then ask a cross-document question whose answer requires retrieval rather than a simple filename lookup.
